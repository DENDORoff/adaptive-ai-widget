# Бизнес-план: Адаптивный ИИ-виджет

## Резюме

**Название (рабочее):** Chamele.AI / AdaptiveWidget
**Категория:** SaaS,客户服务技术 (Customer Support Tech)
**Целевая аудитория:** Малый и средний бизнес (SMB), интернет-магазины, SaaS-компании, агентства
**Ключевое отличие:** Zero-конфигурация, автоматическая адаптация стиля и данных

---

## Целевая аудитория

### Первичная (MVP)
| Сегмент | Характеристики | Боль |
|---|---|---|
| Интернет-магазины | 50–500 товаров, 50–500 посещений/день | Нет времени на настройку чат-бота, всё обновляется каждый день |
| Малый SaaS | 100–1000 пользователей | Документация устаревает, поддержка завалена |

### Вторичная (после MVP)
| Сегмент | Характеристики | Боль |
|---|---|---|
| Корпоративные сайты | Много подразделений, сложная навигация | Чат-бот не понимает структуру |
| Образование | Курсы, вузы | Студенты задают одни и те же вопросы |

## Go-to-market (GTM)

### Первые 3 месяца (MVP)
1. **Продукт:** Использовать наш виджет на 2–3 собственных сайтах (портфолио)
2. **Контент:** Статья «Как сделать чат-бот за 5 минут» + SEO
3. **Продажи:** Холодные письма SMB-магазинам (Shopessa, Wildberries-продавцы), личные контакты
4. **Пилот:** Найти 3–5 бесплатных пилотных партнёров, собрать обратную связь

### 3–9 месяцев
1. **Платные клиенты:** Конвертировать пилоты, холодные продажи через Instagram/Telegram-рекламу
2. **Интеграции:** Shopify, Tilda, WordPress плагины → облегчить подключение
3. **Партнёрская программа:** Агентства, фрилансеры получают 20% с повторных оплат

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Ollama даёт неточные ответы | Средняя | Высокое | Локальный поиск как fallback; контекст ограничен данными сайта |
| Ollama требует железа у клиента | Средняя | Среднее | Гибрид: локальный поиск для простых вопросов, LLM только для сложных |
| Конкуренты скопируют | Средняя | Среднее | Первый movers, бренд, качество экстракции |
| Узкая ниша — мало SMB-клиентов | Низкая | Среднее | Расширение на агентства, нестандартные сайты (образование, медицина) |
| Изменения в Google SEO снижают трафик | Низкая | Низкое | Реклама, партнёрства |
| Стоимость LLM API съедает маржу | Низкая | Низкое | Локальная модель, цена ИИ в тарифе |
| Недостаток доверия у компаний | Средняя | Высокое | Пилоты, кейсы, прозрачная документация |
